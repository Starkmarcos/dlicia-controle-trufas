# 🍫 D'Licia - Controle de Trufas
### 🔑 Credenciais de Demonstração

As credenciais padrão podem ser alteradas diretamente no código-fonte para fins de estudo e personalização.

Sistema desktop desenvolvido em Python para auxiliar pequenos empreendedores no controle de produção, estoque, vendas e finanças de trufas e produtos artesanais.

## 📋 Sobre o Projeto

O D'Licia foi criado para facilitar a gestão de um negócio de produção artesanal, permitindo acompanhar produtos em estoque, registrar vendas, controlar custos e organizar reservas financeiras de forma simples e intuitiva.

## 🚀 Funcionalidades

### 📦 Controle de Estoque

* Cadastro de produtos
* Controle de quantidade disponível
* Atualização e exclusão de produtos
* Edição protegida por senha

### 💰 Controle de Vendas

* Registro de vendas
* Atualização automática do estoque
* Histórico de vendas
* Controle de faturamento

### 🧾 Controle de Custos

* Registro de despesas
* Controle de gastos com produção
* Histórico de custos
* Edição e exclusão de lançamentos

### 🏦 Gestão Financeira

* Controle de caixa
* Reserva para compras
* Reserva para poupança
* Distribuição automática dos valores das vendas

### 🔐 Segurança

* Sistema de login
* Áreas administrativas protegidas por senha

### 🎨 Personalização

* Upload de logotipo personalizado
* Interface gráfica amigável desenvolvida com PyQt6

## 🛠️ Tecnologias Utilizadas

* Python
* PyQt6
* JSON
* Programação Orientada a Objetos (POO)

## 📊 Recursos do Sistema

* Persistência automática de dados
* Interface gráfica moderna
* Controle financeiro integrado
* Histórico de operações
* Edição de registros em tempo real

## ▶️ Como Executar

Instale as dependências:

```bash
pip install PyQt6
```

Execute o sistema:

```bash
python D'licia.py
```
